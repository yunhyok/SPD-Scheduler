PowerSI에서 `Simulation Done.`이 표시되어도 첫 작업이 계속 실행 중으로 남아 후속 작업이 진행되지 않던 문제를 수정했습니다.

- 장시간 실행 중 누적된 자식 프로세스 기록에서 종료·PID 재사용이 확인된 항목을 정리합니다. 이전 버전에서 저장된 실행 기록에도 적용됩니다. 살아 있거나 조회 불가인 solver는 계속 확인합니다.
- 프로세스 신원 확인에 동기화 권한을 필수로 요구하지 않아 읽을 수 있는 PID가 접근 거부로 처리되는 경우를 줄였습니다.
- `실행 중`으로 남은 작업도 우클릭 **수동 완료 처리…** 또는 **제거**로 정리할 수 있습니다. 실제 완료와 결과 저장 여부를 먼저 확인하세요. 수동 정리는 목록만 변경하고 SPD·실행 로그를 보존하며, 후속 작업은 **시작**을 눌러야 진행됩니다.
- 긴 오류 메시지로 창 오른쪽의 시작·일시 중지·지금 확인 버튼과 표 열이 화면 밖으로 밀리던 배치를 수정했습니다. 작은 창에서는 도구 버튼을 줄바꿈하며, 기본 화면을 차콜·중성 회색으로 정리했습니다.

설치 파일: `SPD-Scheduler-Setup-0.2.4.exe`
포터블: `SPD-Scheduler-0.2.4-win-x64.zip`

기존 스케줄러만 트레이 메뉴에서 종료한 뒤 업데이트하세요. PowerSI/PowerDC와 기존 대기열은 유지됩니다. 업데이트 후 **지금 확인**으로 현재 작업을 재확인하고, 저장·종료가 확인되면 **시작**으로 후속 대기열을 진행하세요.

사용자가 보고한 실제 장시간 PowerSI 작업의 재실행 검증은 별도 환경에서 필요합니다. 자동 회귀 테스트와 로컬 UI·패키지 검증 결과는 검증 기록에 기재합니다.
