SPD Scheduler v0.1.5

## 수정 사항

- 예약 실행 시 `The path is empty. (Parameter "path")`로 실패하던 문제를 수정했습니다. 설정 화면이 자동 탐색 경로를 표시해도 저장하지 않으면 실제 경로는 비어 있었으며, 시작 단계에서 이를 검사하지 않던 결함입니다.
- 이제 **시작** 버튼과 트레이의 **대기열 시작**에서 PowerSI 경로를 검사합니다. 비어 있으면 설치 경로를 자동 탐색하고 저장한 뒤 자동 진행을 활성화합니다. 지정한 경로가 잘못되면 다른 설치로 임의 변경하지 않고 설정 확인을 안내합니다.
- 실제 실행 직전에도 경로를 다시 검사합니다. 예약 대기 중 실행 파일이 없어지면 작업을 실패로 소모하지 않고 큐를 일시정지하며 대기 항목·예약을 보존합니다.
- **작업 상세**를 추가했습니다. 상태 셀 더블클릭 또는 행 우클릭으로 오류, 실행 ID/PID, 시각, 로그 위치를 열고 Ctrl+A/C로 복사할 수 있습니다. 실행 폴더를 만들기 전에 실패한 경우 전체 스케줄러 로그 폴더를 안내합니다.
- 대기 작업이 없을 때 실패 건수가 있으면 하단에 계속 표시합니다. 기존의 실패 항목을 업데이트만으로 자동 재실행하지 않습니다.

## 업데이트와 재시도

1. 스케줄러의 트레이 메뉴에서 **종료** 후 `SPD-Scheduler-Setup-0.1.5.exe`를 설치합니다.
2. 설정의 PowerSI 경로를 확인하고 변경했다면 **저장**합니다.
3. 기존 실패 행을 우클릭하여 **다시 대기**를 선택합니다. 필요하면 예약 시간을 새로 지정합니다.
4. **시작**을 누릅니다. 지난 예약을 그대로 두면 다른 작업 상태를 확인한 뒤 실행 가능한 시점에 진행합니다.

PowerSI·BbsCon 동시 진행 정책과 자체 작업의 저장·정리 기준은 유지합니다.

## 검증 범위

회귀 테스트 135개 통과. 빈 경로 자동 탐색과 저장, 설치 없음, 잘못된 명시 경로, 예약 대기 중 파일 삭제, 실행 직전 재검사, 큐·예약 보존, 실패 표시를 합성 파일과 가짜 실행기로 검사했습니다. 작업 상세의 오류 텍스트 선택과 로그 폴더 연결, 설정 저장, 100%·150% 수동 배율 배치도 확인했습니다.

이 PC에서는 실제 PowerSI, 사용자 BAT/Tcl, 실제 SPD 시뮬레이션을 실행하지 않았습니다. 이 수정은 실행 전 경로 오류를 해결하며, PowerSI GUI 시작·시뮬레이션·저장·종료의 전체 연동 검증은 별도 허용 PC에서 필요합니다.
