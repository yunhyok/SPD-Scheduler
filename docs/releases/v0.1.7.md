SPD Scheduler v0.1.7

## 수동 완료와 목록 정리

자동 시작·완료 근거를 읽지 못해 `확인 필요`로 보류된 작업을 사용자가 정리할 수 있도록 했습니다. v0.1.6의 프로세스 조회 복구 기능도 포함합니다.

- 행을 우클릭하여 **수동 완료 처리…**를 선택합니다. 시뮬레이션 완료와 결과 저장을 직접 확인한 뒤 승인하면 **완료 (수동)**로 표시합니다. 자동 완료 검증과 구분되며, 이전 오류·실행 정보·로그를 보존합니다. `확인 필요`와 `실패` 항목에 사용할 수 있습니다.
- `확인 필요` 항목도 기존 **제거** 버튼, 우클릭 **제거 (Delete)**, Delete 키에서 확인 창을 거쳐 목록에서 제거할 수 있습니다. 원본 SPD와 실행 로그는 삭제하지 않습니다.
- 수동 정리는 PowerSI에 저장·종료·재실행 명령을 보내지 않습니다. 해당 항목의 자동 관리를 끝내고 후속 큐를 일시정지합니다. **시작**을 누르면 외부 PowerSI 상태를 다시 확인한 뒤 다음 작업을 진행합니다.
- 확인 창은 취소가 기본입니다. 시작·실행·저장 중인 항목은 수동 정리할 수 없으며, 확인 창을 연 뒤 실행 ID가 바뀌면 이전 확인으로 처리하지 않습니다.
- 수동 처리 내역은 작업 ID·실행 ID·PID·이전 오류와 함께 로컬 로그에 기록합니다. 목록 저장이 실패하면 메모리의 상태 변경도 되돌립니다.

## 업데이트 후 사용

1. 스케줄러만 트레이 메뉴의 **종료**로 닫고 `SPD-Scheduler-Setup-0.1.7.exe`를 설치합니다.
2. PowerSI에서 완료 및 결과 저장 상태를 직접 확인합니다.
3. 보류된 행을 우클릭하여 **수동 완료 처리…**를 승인하거나, **제거**로 목록에서 지웁니다.
4. 후속 작업을 진행하려면 **시작**을 누릅니다. 이미 끝낸 파일을 **다시 대기**로 돌릴 필요는 없습니다.

## 검증 범위

회귀 테스트 154개 통과. 살아 있거나 조회되지 않는 PID가 있는 보류 작업의 수동 정리, PowerSI 명령 미발행, 원본·로그 보존, 재시작 후 기록 유지, 수동 처리 후 일시정지, 외부 시뮬레이션 감시 유지, 오래된 실행 ID 거부, 저장 실패 복원, 관측 중 동시 변경 차단을 합성 데이터와 가짜 어댑터로 검사했습니다.

안전 모드의 합성 UI에서 메뉴 활성 조건, 확인·취소 기본 동작, 제거 버튼·우클릭·Delete 키, 수동 완료 표시와 작업 상세, 확인 창을 연 뒤 실행 ID가 변경된 경우의 거부를 확인했습니다.

이 PC에서는 실제 PowerSI, 사용자 BAT/Tcl, 실제 SPD 시뮬레이션을 실행하지 않았습니다. 수동 완료는 사용자의 확인 기록이며 결과 저장 성공을 자동 검증한 것으로 간주하지 않습니다. 시작·완료 신호를 관측하지 못한 실제 연동 원인은 별도 환경에서 추가 확인이 필요합니다.
