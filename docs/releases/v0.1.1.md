SPD Scheduler v0.1.1

## 변경 사항

- PowerSI 상태를 읽을 때 GUI 스케줄러 EXE를 매번 실행하던 방식을 전용 console-subsystem 보조 프로그램으로 변경했습니다. 창 생성 없이 실행하여 Windows의 GUI 시작 대기 커서가 반복되는 원인을 제거했습니다.
- 기본 확인 간격을 2초에서 **1분**으로 늘렸습니다. 설정의 **확인 간격 (분)**에서 1~60분으로 변경할 수 있습니다. 기존 설정 파일에도 기본 1분이 적용됩니다.
- 분 단위 확인 간격에 맞춰 유휴 측정의 관측 누락 기준을 조정했습니다. CPU·I/O·메모리 및 명시적인 실행 상태의 판정 기준은 유지합니다.
- 현재 작업 완료 확인과 다음 작업 시작, 예약 실행은 설정한 확인 주기에 맞춰 이루어집니다. 예약 시각 직후가 아니라 다음 확인 시점에 시작될 수 있습니다.

## 설치와 업데이트

Windows 10·11 x64용 사용자 단위 설치파일이며 .NET 10 런타임을 포함합니다. 상태 읽기용 보조 EXE도 함께 설치됩니다.

1. 기존 SPD Scheduler 트레이 메뉴에서 **종료**를 선택합니다. 진행 중인 PowerSI는 유지됩니다.
2. `SPD-Scheduler-Setup-0.1.1.exe`를 실행하여 기존 설치 위치에 업데이트합니다.
3. 다시 실행하면 기존 큐·예약·설정이 복구되고 신규 작업 실행은 일시정지 상태입니다. 내용을 확인한 뒤 **시작**을 누르세요.

## 검증 범위

설치·업데이트 관리를 위해 정식 Release로 게시합니다. PowerSI GUI 연동의 전체 실측 검증이 완료됐다는 의미는 아닙니다. 실제 PowerSI를 실행하지 않는 회귀 테스트와 전용 보조 EXE의 PE subsystem/무해한 입력 실행을 확인합니다. 실제 워크스테이션에서 포인터 증상의 개선과 모드별 시뮬레이션 결과는 추가 확인이 필요합니다.

기존 PowerSI를 저장하거나 종료하는 동작은 추가하지 않았습니다. 외부 작업의 저부하 유휴 추정에는 오판 가능성이 있습니다.
