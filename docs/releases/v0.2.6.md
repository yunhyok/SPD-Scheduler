SPD 파일별 시뮬레이션 스레드 수 설정 추가. 복잡한 도면 실행 전 리소스 사용 수준 조절 가능.

- **대기 행 우클릭 → 리소스 사용 (스레드)**에서 **16·24·32·48·64** 선택. 기본값 **64 스레드(최대)**.
- 파일별 선택값을 목록의 **스레드** 열과 작업 상세에 표시. 여러 대기 행 동시 변경 지원.
- 선택 즉시 저장. 앱 재시작·재시도 후 유지. 실행을 시작한 항목의 변경 차단.
- SPD 열기 후 **Start Simulation 전에 적용**. 리소스 설정 실패 시 시작 차단 및 오류 기록.
- PowerSI·PowerDC에 제공된 `HybridComputerResource` Tcl 명령 적용. 로컬 계산 사용 및 분산 solver 해제. 기존 CPU·디스크 감시와 순차 실행 조건 유지.
- 기존 큐는 64 스레드 기본값으로 복구. **v0.2.6에서 저장한 큐는 구버전에서 열 수 없음.** 구버전의 설정 무시 방지 목적.

설치 파일: `SPD-Scheduler-Setup-0.2.6.exe`
포터블: `SPD-Scheduler-0.2.6-win-x64.zip`

기존 스케줄러를 트레이 메뉴에서 종료한 뒤 업데이트할 것. 설치 화면에서 기본 Program Files 경로 확인 및 다른 드라이브·폴더 선택 가능. 기존 대기열·설정 유지.

검증: Release 자동 회귀 테스트 228개, Tcl 모의 실행 20개 통과. 설정 저장·마이그레이션·재시도 유지·실행 전 변경 차단·설정 거부 시 시작 차단 확인. 기본·최소 창 및 100%·150%·200% 배율의 WinForms 배치 검사 포함. 실제 Windows DPI 변경 시험은 아님.

**스레드 수는 CPU 점유율(%)·메모리·디스크 사용량의 상한이 아님.** 낮은 스레드 수에서도 해석 모드와 도면에 따라 PC 응답성이 저하될 수 있음. 실제 대형 도면의 자원 사용량과 PowerSI·PowerDC 버전별 명령 적용은 별도 실기 검증 필요.
