안정성 버그 수정 및 대기열 관리·대화상자·트레이 UI/UX 개선.

### 오류 수정 및 안정성 개선
- **SPD 완료 규칙 탐색 공유 잠금 수정:** PowerSI/PowerDC가 `.spd` 파일을 읽기/쓰기 핸들로 연 상태에서도 완료 규칙을 정상 판별하도록 파일 공유 모드(`FileShare.ReadWrite | FileShare.Delete`)로 수정.
- **Tcl 제어 파일 폴링 보호:** 실행 중 `control.txt` 교체 시 일시적 파일 잠금이 발생해도 Tcl `scheduler_poll` 루프가 중단되지 않도록 `catch` 및 핸들 정리 추가.
- **절전 복귀 시 자동 재확인 연동:** Windows 절전 복귀 이벤트(`SystemEvents.PowerModeChanged`)를 감지해 예약 시각 및 실행 상태를 즉시 재확인.
- **재시도 중복 차단 및 저장 실패 롤백:** `다시 대기(Retry)` 시 동일 SPD·프로그램의 중복 대기/실행을 차단하고, `Remove`/`SetSchedule`/`Retry`/`Skip`/`UpdateSettings`/`MoveQueued` 저장 실패 시 메모리 상태를 안전하게 롤백.
- **실행 폴더 누락 방어 및 표시 수정:** 실행 폴더가 없는 상태의 `InspectAsync` 예외를 방지하고, `&` 문자가 포함된 긴 파일명의 마퀴 폭 계산 오류와 유휴 시 30 FPS 타이머 점유를 수정.

### UI / UX 개선
- **대기 작업 순서 이동:** 대기 행 우클릭 **순서 위로/아래로** 및 `Alt+↑`/`Alt+↓`로 FIFO 실행 순서를 직접 조정.
- **실시간 상태 배지 및 큐 요약:** 헤더에 현재 모드 배지(`자동 진행 중`·`실행 중`·`확인 필요`·`일시 중지`)를 표시하고, 하단에 상태별 작업 건수 요약 및 툴팁을 제공.
- **빈 목록 안내 및 선택 연동 제어:** 대기열이 비어 있을 때 드래그 앤 드롭 안내를 표시하고, 선택 상태에 따라 도구 버튼과 우클릭 메뉴를 동적으로 활성화/비활성화.
- **대화상자 다크 테마·고DPI·편의성 개선:**
  - **실행 예약** 창에 빠른 예약 프리셋(`+10분`·`+30분`·`+1시간`·`내일 09:00`) 및 고DPI 레이아웃 적용.
  - **감시 상세**·**작업 상세** 창에 `Esc` 닫기, **클립보드 복사**, **새로 고침** / **로그 폴더 열기** 버튼 추가.
  - **설정** 창의 고DPI 배율 클리핑 방지, 저장 폴더 바로 열기 버튼, 규칙 테이블 편집 오류 방어 추가.
- **트레이 메뉴·알림 강화:** 트레이 메뉴에 현재 상태 요약 및 **지금 확인**을 추가하고, 창이 트레이에 숨겨진 상태에서 확인 필요·실패·대기열 완료 전환 시 알림 표시.
- **단축키 확장:** `Enter`(작업 상세), `F5`(지금 확인), `Ctrl+A`(전체 선택), `Alt+↑/↓`(순서 이동) 및 파일명 열 더블클릭 지원.

설치 파일: `SPD-Scheduler-Setup-0.2.7.exe`
포터블: `SPD-Scheduler-0.2.7-win-x64.zip`
