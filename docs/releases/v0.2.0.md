SPD Scheduler v0.2.0

## PowerDC 작업 추가

- 새 SPD 항목은 기본 PowerSI로 추가합니다. 대기 행을 **우클릭 → 실행 프로그램 → PowerDC**로 변경할 수 있으며 프로그램 열에도 선택을 표시합니다. 여러 대기 항목을 함께 바꿀 수 있습니다.
- 설정에 별도 PowerDC 실행 경로와 자동 찾기를 추가했습니다. 사용하는 프로그램의 경로만 필요하며 PowerSI와 PowerDC 실행 파일을 혼동하면 실행 전에 안내합니다.
- PowerSI·PowerDC 작업을 한 목록에서 순차·예약 실행합니다. 두 프로그램과 solver 자식 프로세스를 함께 감시합니다. 실행 중인 작업의 프로그램은 변경할 수 없습니다.
- 완료 판정 규칙은 프로그램별로 구분합니다. PowerDC 전처리는 시작 증거로만 사용하고, 현재 실행의 GUI 전이 또는 PowerDC 전용 로그 규칙으로 완료를 확인합니다.
- 완료 승인 후 SPD와 실행별 폴더의 `powerdc-results.xml`을 저장합니다. XML 저장 실패·빈 파일이면 프로그램을 유지하고 후속 작업을 보류합니다. 결과는 행 우클릭 **로그 폴더 열기**에서 확인합니다.

SPD는 선택한 프로그램에서 바로 Start Simulation이 가능한 상태로 저장되어 있어야 합니다. 프로그램 선택은 실행 파일을 지정하며 IR Drop·E/T 등 저장 모드를 강제로 변경하거나 자동 변환하지 않습니다. PowerDC로 열 때 저장 모드가 복원되는지 실제 환경에서 확인해야 합니다.

## 업데이트

스케줄러만 트레이 메뉴에서 종료한 뒤 `SPD-Scheduler-Setup-0.2.0.exe`를 설치하세요. 기존 PowerSI 목록·예약·실행 기록은 유지하며 새 항목도 PowerSI가 기본입니다. 앱 재시작 후 신규 자동 진행은 일시정지 상태이므로 목록 확인 후 **시작**을 누르세요.

목록 저장 형식이 버전 2로 바뀝니다. 구버전은 이 목록을 읽지 못하며, PowerDC 선택을 무시하고 PowerSI로 실행하는 것을 방지합니다. v0.2.0에서 저장한 큐는 이전 버전으로 열 수 없습니다.

## 검증 범위

합성 회귀 테스트 **202개 통과**, 안전 UI의 100%·150% 배율에서 프로그램 선택·설정·수동 정리 검사 통과. 가짜 프로세스·시간·로그로 혼합 큐, 예약 우선순위, 이전 목록 복구, 프로그램별 규칙 분리, PowerDC solver 감시, 완료 재확인 및 저장 실패 차단을 검사했습니다.

실제 PowerSI·PowerDC, 사용자 BAT/Tcl, 실제 SPD는 이 PC에서 실행하지 않았습니다. PowerDC GUI `-tcl`, 저장 모드 복원, 실제 완료 문구, XML 저장·재열기는 별도 허용 PC에서 검증해야 합니다. 근거가 부족하면 `확인 필요`로 보류하며 자동으로 완료 처리하지 않습니다. 설치·업데이트용 정식 Release이며 실제 연동 검증 완료를 의미하지 않습니다.
