PowerSI 계산 종료 후 디스크 후처리가 계속되는 동안 다음 큰 도면이 열리던 문제 수정.

- 로컬 물리 디스크별 최근 1초 활성 시간 확인. 디스크별 최댓값 **80% 이상이면 자동 진행 보류**.
- 낮은 CPU, `Simulation Done.`, 외부 BbsCon 병행 허용 상태에도 동일 기준 적용.
- 자체 작업의 저장·종료 승인과 최종 완료 처리에도 디스크 검사 적용. 이미 전달된 저장·종료 명령은 유지.
- 부하 초과·조회 실패 후 설정된 유휴 시간(기본 60초) 동안 저부하 관측 후 재개. 프로세스 종료와 실행 직전 재검사에서도 대기 유지.
- **감시 상세**에 디스크별 활성 시간, 80% 한도, 대기 사유 표시.
- 기존 CPU·메모리·프로세스 I/O 설정 및 완료 근거 유지.

설치 파일: `SPD-Scheduler-Setup-0.2.5.exe`
포터블: `SPD-Scheduler-0.2.5-win-x64.zip`

기존 스케줄러를 트레이 메뉴에서 종료한 뒤 업데이트할 것. 설치 화면에서 기본 경로 확인 및 다른 드라이브·폴더 선택 가능. 기존 대기열·설정 유지.

검증 범위: 합성 프로세스·로그 기반 회귀 테스트, 로컬 Windows 실제 디스크 카운터 조회, Windows 설치·재설치 검사. 실제 대형 PowerSI 도면의 장시간 후처리는 별도 실기 검증 필요.

제한: 모든 로컬 디스크를 검사하므로 다른 프로그램의 디스크 부하도 대기 원인이 됨. 네트워크 서버 디스크와 확인 사이의 짧은 활동은 직접 검증하지 않음. 카운터 조회 실패 시 자동 진행 보류.
