빈 대기열에 첫 SPD 파일을 추가(드래그 앤 드롭·파일 추가)할 때 발생하던 `NullReferenceException` 긴급 수정.

### 수정 내용
- **빈 목록 첫 파일 추가 시 `NullReferenceException` 수정:** 표시된 `DataGridView`가 비어 있는 상태에서 `Rows.Add` 호출 직후 행 태그(`Row.Tag`)가 채워지기 전에 WinForms가 `SelectionChanged`를 동기 발생시켜 `SelectedIds()`에서 `null` 언박싱 예외가 발생하던 문제를 수정.
  - `RefreshQueue` 및 순서 이동 갱신 중 `SelectionChanged` 재진입을 차단하고, 갱신 완료 후 선택 상태를 일괄 반영.
  - `SelectedIds()`가 `OfType<Guid>()`로 안전하게 필터링하도록 방어 로직 추가.
- **비동기 UI 이벤트 핸들러 예외 처리 보강:** 드래그 앤 드롭, 더블클릭, 단축키, 컨텍스트 메뉴의 비동기 핸들러에서 예기치 않은 예외가 JIT 디버깅 대화상자로 전파되지 않고 안내 메시지로 처리되도록 개선.
- **회귀 테스트 추가:** 실제 표시(`Show()`) 상태의 빈 그리드에 첫 파일 추가·추가 등록·제거 시나리오를 자동 회귀 테스트에 포함.

설치 파일: `SPD-Scheduler-Setup-0.2.8.exe`
포터블: `SPD-Scheduler-0.2.8-win-x64.zip`

기존 스케줄러를 트레이 메뉴에서 종료한 뒤 업데이트하세요. 기존 대기열과 설정은 그대로 유지됩니다.

검증: Release 자동 회귀 테스트 238개 전체 통과(표시된 빈 그리드 첫 파일 추가 회귀 테스트 포함), Windows 설치·재설치 검사 통과.
